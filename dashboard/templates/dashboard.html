        ⇄ HOW THE ESP32 CONNECTS

        The ESP32 DevKit V1 sends a JSON telemetry payload to this endpoint every 1–3 seconds. The dashboard validates it, stores it, and updates the screen — nothing else to wire.

        POST http://<host>:<port>/api/update
        Expected payload (see docs/api_contract.md):
        • device_id — string, e.g. "smart-travel-bag-01"
        • timestamp — ISO-8601 string
        • weight_kg, locked, bag_open, movement_detected, distance_cm
        • gps — {valid, latitude, longitude} only when a valid fix exists
        • sensors — {rfid, servo, hx711, mpu6050, reed_switch, ultrasonic, gps, buzzer, esp32_cam}
        • rfid_result — "accepted" / "rejected"
